# routers - camada HTTP do Conversas (inbox WhatsApp)

Endpoints do inbox (`conversations`, `templates`, `media`, `tags`, `notes`, `variables`,
`quick_replies`, `settings`, `api_config`), o webhook da Meta e as paginas Jinja. `webhook.py` recebe
trafego da internet e e a superficie externa mais sensivel do repo.

## Responsibility

Traduzir HTTP em operacao de conversa e delegar integracao externa para `app/services/`. Chamada a Meta
Cloud API nao e feita aqui (`services/whatsapp.py`), persistencia de mensagem outbound nao e feita aqui
(`services/outbound.record_outbound_message`) e politica de midia nao e decidida aqui
(`services/media_policy.py`).

## Key patterns

- `webhook.py` valida a assinatura `X-Hub-Signature-256` com `hmac`/`hashlib` contra `META_APP_SECRET`
  antes de processar qualquer payload; GET responde o desafio com `META_VERIFY_TOKEN`.
- Envio outbound sempre termina em `record_outbound_message()` + `classify_wa_response()` - persistir
  `sent` sem confirmacao da Meta e a classe de bug que esse contrato elimina.
- A regra das 24h vem de `models.conversation.service_window_open`; nao reimplemente o calculo na rota.
- Auth via `from app.auth import get_current_user, User` - o Conversas le a MESMA tabela `users` do CRM.
- Consulta de lead/pipeline vai por `services/crm.py` (query direta no banco compartilhado), nunca por
  HTTP para o CRM.
- Listagem usa `selectinload` + `set_committed_value` para evitar N+1 no inbox.

## Local conventions

- Todo teste que toca este diretorio precisa conter a string `CONVERSAS_DIR` - e o discriminador que
  manda o arquivo para o job Python 3.12 no CI.
- Nao importe `app` do CRM e do Conversas no mesmo processo: os pacotes tem o mesmo nome.
- Timeout de chamada ao agente n8n e deliberadamente alto (execucoes de 1-3 min sao normais); nao
  reduza sem ler o comentario `CONV-AGENT-01` em `webhook.py`.
- `conversations.py` ja passa de 1200 linhas: acrescente nele em vez de reorganizar, e proponha extracao
  so quando for o objetivo da tarefa.
- Comentarios de decisao levam o codigo do work package (`CONV-01`, `CONV-WINDOW-01`, `CONV-08b`).
