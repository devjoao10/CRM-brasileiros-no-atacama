# schemas - contratos Pydantic v2 do CRM

Schemas de entrada e saida das rotas `/api/*`. Sao a fronteira de validacao do sistema: o que passa por
aqui e considerado bem formado pelo resto do codigo.

## Responsibility

Descrever a forma dos dados que entram e saem da API, com validacao de formato, tamanho e tipo. Nao
representa persistencia (`app/models/`), nao contem regra de negocio (service ou router) e nao faz acesso
a banco. Regra que depende de estado do banco ("esse funil existe?") nao e validada aqui.

## Key patterns

- Trio por recurso: `<Coisa>Base` -> `<Coisa>Create` / `<Coisa>Update` -> `<Coisa>Response`,
  mais `<Coisa>ListResponse` quando a rota pagina.
- Todo campo relevante usa `Field(...)` com `min_length`/`max_length` e `description` em PT-BR - a
  description alimenta o OpenAPI.
- Campo opcional e `Optional[...]` com default explicito; dict/list usam `default_factory`.
- Regra de formato mora em `@field_validator`; regra de negocio nao.
- Constantes de dominio compartilhadas ficam no schema e sao importadas pela rota
  (`DESTINOS_PRINCIPAIS` em `schemas/lead.py`, reexportado por `routers/leads.py`).
- Schema que compoe outro importa o schema, nunca o model (`LeadResponse` usa `TagResponse`).

## Applied rules

Rules active in this directory - read them before touching code here:

- @.claude/rules/fastapi/coding-standards.md - `response_model` sempre a partir daqui; nunca devolva o
  objeto SQLAlchemy direto para o cliente.
- @.claude/rules/ecc/python/fastapi.md - Pydantic v2 (`field_validator`, `model_config`), sem API v1.
- @.claude/rules/06-security.md - resposta expoe so o necessario; nao adicione `hashed_password`,
  `api_key` ou segredo interno em nenhum `*Response`.

## Local conventions

- Campo novo em `LeadCreate`/`LeadUpdate` tem coluna correspondente em `app/models/lead.py` e, se a
  tabela ja existe em producao, um script em `migrations/`.
- Nao replique aqui as validacoes que o banco ja garante (unicidade, FK); valide formato e limite.
- Mensagem de validador e em PT-BR e descreve o que o cliente deve corrigir.
